# ТИХИЙ БОР · Forest Front

Карта для перестрелки в одном файле: `forest_map_camp.html` (three.js 0.166 с unpkg + встроенный ammo.js).
Открыть файл в браузере (Chrome/Edge/Firefox). Параметры: `?q=potato|low|medium|high`, `?weather=clear|…`.

Управление: мышь — обзор, WASD — движение, Space/E — вверх/прыжок, C/Q — вниз/присесть, Shift — быстрее,
ЛКМ — граната, ПКМ — выстрел, X — перезарядка, F — прожектор (у ящика — пополнить боезапас), G — дрон ⇄ пешком,
M — карта, B — артналёт, K — погода, N/1–4 — время суток, Esc — пауза.

Пулемётные гнёзда (10 шт., M2HB 12,7 мм): пешком подойти к рукояткам и нажать `E`. ЛКМ — огонь (камера сверху-сзади),
ПКМ — прицел через целик, `X` — сменить ленту (100 в ленте + 300 в запасе), `E`/`G` — отойти.
Вышки: лестница твёрдая, пешком `W` у лестницы — лезть. `L` в будке — прожектор; пока стоите рядом, луч идёт за взглядом.
`F3` — FPS, GPU-время по проходам и время логики на CPU.

## Гранаты M67 и M84

`m67_grenade_model.html` (осколочная M67) и `flashbang_m84.html` (светошумовая M84) — самодостаточные файлы,
собранные из общего ядра в `grenades/` (three.js 0.166.1 с unpkg, как у карты). Открыть в браузере с WebGL 2.

* Механика: клип (M67) → чека (тянуть кольцо мышью вдоль оси; подклинивание, срыв, возврат если отпустить раньше)
  → рычаг зажат, пока зажата кнопка мыши → отпустил — рычаг отлетает, ударник, замедлитель (M67 4–5,5 с, M84 1–2,3 с,
  случайно) → бросок резким движением мыши → взрыв → повтор в слоу-мо (таймлайн с перемоткой).
* Клавиши: Space — следующее действие / повтор, T — бросок вперёд, D — уронить, R — сброс, M — звук, Esc — выход из повтора.
* Параметры: `?q=low|med|high`, `?scene=studio|range`, `?seed=N` (детерминированный взрыв), `?fuse=сек`,
  `?bench=1` — стенд: сам проводит подрыв и выводит p50/p95/p99 времени кадра, число кадров > 33 мс на первом
  взрыве, новые шейдеры во время взрыва и `renderer.info` (также в `window.__BENCH__` и в консоли).

Разработка: `cd grenades && npm install && npm run build` (исходники — `grenades/src`, устройство — `grenades/ARCHITECTURE.md`).
